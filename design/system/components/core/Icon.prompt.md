# Icon

Every glyph in the system. Lucide, recoloured through a CSS mask so it inherits accent or text colour.

```jsx
<Icon name="chevron-right" size={18} color="var(--accent)" />
```

Used names: chevron-right, files, file-x, rotate-cw, crop, sun, scan, wand-sparkles, trash-2, camera, share-2, plus.
